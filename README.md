# Student Management System

## Description

A console-based Student Management System developed using Python and SQLite.

The application allows users to add, view, search, update, and delete student records through a simple command-line interface.

## Features

- Add student records
- View all students
- Search students by roll number
- Update student information
- Delete student records
- Input validation
- Exception handling
- SQLite database integration
- Modular project structure

## Technologies Used

- Python
- SQLite
- SQL
- Object-Oriented Programming
- Git
- GitHub
